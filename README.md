# Tuga Stats Lens: releases

Instaladores e engine packs do Tuga Stats Lens (Windows 10/11, 64 bits). Este repositório só tem ficheiros de release, sem código.

- **Instalar**: na release mais recente, descarregar `Tuga.Stats.Lens_<versão>_x64-online-setup.exe` (pequeno; descarrega o motor, cerca de 1,8 GB, na primeira utilização) ou `Tuga.Stats.Lens_<versão>_x64-setup.exe` (completo, funciona sem rede).
- **Actualizar**: a app procura versões novas sozinha.
- As releases `pack-<versão>` são o motor, descarregado pela app. Não são para instalar à mão.

O Windows SmartScreen avisa na instalação (a app ainda não tem assinatura de código): "Mais informações" e depois "Executar assim mesmo".
